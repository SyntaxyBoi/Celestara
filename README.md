# **Celestara**

**Celestara** is a Fabric 1.20.1 visual overhaul for Minecraft’s night sky.

This mod makes the night sky feel more alive by adding subtle star movement, twinkling stars, shooting stars, colorful comets, and rare meteor shower nights. The goal is to make Minecraft nights feel more interesting and atmospheric while still keeping a Vanilla+ style.

**Celestara** is meant to be a simple, purely visual improvement for Vanilla+, survival, fantasy, and atmospheric modpacks.
